# Example Inputs for draft_cold_email

Use one of the following input formats to generate personalized cold emails:

---

## Example 1: Basic Prospect Data

```
Business: Mike's Plumbing
Owner: Mike Johnson
Location: Seattle, WA
Website: mikesplumbing.com
Gap: No online booking

What I'm Selling: AI chatbot that handles booking and lead capture 24/7
My Name: Alex
```
