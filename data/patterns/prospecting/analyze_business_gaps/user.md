# Example Inputs for analyze_business_gaps

Use one of the following input formats to generate a gap analysis:

---

## Example 1: Website URL + Context

```
Business: Mike's Plumbing Services
Website: https://mikesplumbing.com
Location: Portland, OR
Industry: Residential Plumbing

What I'm selling: AI chatbot for 24/7 lead capture and online booking

Please analyze for gaps related to:
- Lead capture capabilities
- Online booking/scheduling
- Chat or instant response
- Mobile experience
```

## Example 7: Detailed Analysis Request

```
Business: Bright Smile Orthodontics
Website: www.brightsmileortho.com
Location: San Diego, CA
Industry: Orthodontics/Dental Specialty

Business Context:
- 2 orthodontists, 8 staff
- Mainly Invisalign and traditional braces
- Target: Teens and adults
- Competition: 15+ orthodontists within 10 miles
- Average case value: $5,000-7,000

I noticed from their site:
- No virtual consultation option
- No treatment cost calculator
- Contact form is 8 fields long
- No patient reviews visible
- Stock photos only
- Copyright says 2020

My services I could sell:
1. Virtual consultation booking system
2. AI chat for treatment questions
3. Payment/financing calculator widget
4. Review aggregation display
5. Before/after gallery

Please provide detailed gap analysis with:
- Revenue impact estimates
- Specific pitch angles for outreach
- Priority ranking of gaps
- Competitive comparison points
```
