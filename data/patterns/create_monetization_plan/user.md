# Example Inputs for create_monetization_plan

Use one of the following input formats to generate a monetization roadmap for your technical assets:

---

```
My Assets:

- EIN obtained, business bank account set up
- No employees, solo founder

Technical Infrastructure:
- VPS: Hetzner dedicated server (32GB RAM, 8 cores, 1TB SSD)
- Domains: myagency.com, clientname-ai.com (5 client-ready domains)
- Fabric installed with all patterns
- OpenRouter API access (all major models)

Fabric Patterns I Want to Monetize:
- audit_business_website (for lead generation)
- create_lead_guardian (AI chatbot/SMS agent)
- build_sales_funnel (marketing consulting)
- automate_business_plan (strategy deliverable)
- summarize_meeting (productized service)

Skills:
- Can write Python/Bash scripts
- Basic web development (can deploy simple frontends)
- Comfortable with APIs and webhooks
- No sales experience

Target Market Ideas:
- Local businesses in Seattle area
- Online: SaaS founders, coaches, agencies

Current Situation:
- Full-time job (want to transition out in 6-12 months)
- Can dedicate 10-15 hours/week initially
- $0 revenue so far, just exploring

Goals:
- First paying client within 30 days
- $5k/month recurring within 6 months
- Eventually replace $120k/year salary
```
