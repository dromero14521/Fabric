# Setup Payment Integration

Production-ready Stripe/PayPal integration with security best practices.

## What You'll Get
- Complete integration code (frontend + backend)
- Webhook handlers with signature verification
- Database schema for transactions
- Security checklist
- Testing guide with test cards
- Error handling patterns

## What to Provide
- Payment provider (Stripe, PayPal, or both)
- Pricing model (one-time, subscription, usage-based)
- Technology stack (Next.js, React, Vue, etc.)
- Currency requirements
- Webhook events needed

## Example Input
```
Payment provider: Stripe
Pricing model: Subscription (monthly and annual options)
Tech stack: Next.js 14 with TypeScript, PostgreSQL
Currencies: USD, EUR
Webhooks needed: payment_intent.succeeded, customer.subscription.updated, invoice.payment_failed
Compliance: Need SCA for European customers
```
